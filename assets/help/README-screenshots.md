# Pixaroma Help - node pictures needed

Every node already gets an automatic wiring diagram in the Help browser, drawn
from the node itself. A photo is only needed where the node's FACE is the thing
being explained - a picker, a preview, a panel - because that part is HTML and
cannot be drawn from the node definition.

## How to take them

1. Open the workflow **Pixaroma help screenshots** from the Workflows sidebar.
2. Pick any image on the small loader beside the nodes that look empty.
3. Zoom so the node fills a good part of the screen, then **Win+Shift+S** and
   drag around JUST the node, no canvas background.
4. Paste into any image editor and save into `ComfyUI/custom_nodes/ComfyUI-Pixaroma/assets/help/`

**Filename:** the node name exactly as shown, e.g. `Load Image Pixaroma.jpg`.
A caption above each node in that workflow shows the name so it can be copied.
JPG, PNG or WebP all work. Around 600-900 px wide is plenty.

Nothing breaks if a picture is missing - that node just shows its diagram
alone - so these can be done in any order and stopped at any point.
